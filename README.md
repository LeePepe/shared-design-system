# shared-design-system

Shared SwiftUI design-system library (`NativeDesignKit`) for iOS and macOS,
built on [`shared-design-tokens`](https://github.com/LeePepe/shared-design-tokens).

- Agents and contributors: start with [AGENTS.md](AGENTS.md).
- Architecture: [layer map](docs/architecture/tech-context.md).
- Visual theme: [Strata v0.2 rules](docs/strata-theme-v0.2.md) (accepted direction; native implementation pending).
- Consumers: read `ai/` from the exact release you pin.
