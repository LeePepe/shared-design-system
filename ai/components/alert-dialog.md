# StrataAlertDialog

`StrataAlertDialog` is the native SwiftUI alert-style presentation built on
the Strata dialog contract. It provides explicit dismissal policy and action
roles for confirmation or destructive flows; configuration errors are surfaced
without fallback behavior.

Use the explicit `StrataTheme`, keep the action set short, and provide clear
localized labels. Product state and presentation ownership remain with the
caller.
